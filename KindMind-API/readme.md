# KindMind API Log 
====================

Objectives:
(Open weather API)
What will the App do?

- [ ] Allow users to register, log in securely and access their own journal data.<br>
- [ ] Allow users to create, view, edit and delete journal entries stored in MySQL.<br>
- [ ] Record mood, energy level, free time, timestamp and optional weather data with each entry.<br>
- [ ] Allow users to search entries by keyword, filter by mood and sort entries by date.<br>
- [ ] Use a Weather API to store weather conditions alongside journal entries.<br>
- [ ] Generate simple rule-based recommendations based on mood, energy, time available and weather.<br>
- [ ] Show basic analytics such as most common mood, entries per mood and journaling frequency.<br>
